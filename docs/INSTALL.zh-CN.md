# QRCS 安装与使用

## 安装到 Edge

1. 将 ZIP 解压到一个准备长期保留的位置。开发目录也可直接使用 `D:\DSH_WorkFolder\QRCS\extension`。
2. 在 Edge 中打开 `edge://extensions/`。
3. 打开「开发人员模式」。
4. 点击「加载解压缩的扩展」。
5. 选择直接包含 `manifest.json` 的文件夹。
6. 确认扩展列表出现「QRCS 二维码识别」。如需要，在工具栏扩展菜单中固定其图标。

加载后请保留源文件夹，移动或删除它会影响扩展后续使用。ZIP 不应直接拖入浏览器；请先解压并加载目录。

其他支持 Manifest V3 的桌面 Chromium 浏览器可尝试在其扩展管理页使用同样的「加载解压缩扩展」方式，具体兼容性需实测。

## 右键识别图片

在二维码图片上右键，选择「QR码识别」。网页内会出现小结果浮层，不新建系统窗口。

- 链接：显示完整网址及目标主机，点击「跳转」在新标签页打开。
- 文本、Wi-Fi、名片等：显示原文，点击「复制内容」使用。
- 「取消」、右上角关闭按钮或 Esc：关闭本次浮层。

原图无法读取时会尝试网页截图。如果截图也无法识别，可点击「重新框选」。

## 截图框选

1. 把需要识别的二维码滚动到当前可见区域。
2. 点击 QRCS 工具栏图标。
3. 按住鼠标左键拖出选区，包含完整二维码和四周留白。
4. 松开鼠标进行识别。

普通网页直接出现框选界面，识别后显示页内浮层；独立图片等无法注入脚本的页面，会使用工具栏紧凑弹层框选。若没有自动展开，点击带 `QR` 标记的扩展图标。按 Esc 或点击「取消」退出。结果显示不创建额外系统窗口或任务栏图标。

## 识别失败

- 放大二维码后重新截取；选区需包含四角与留白。
- 对多二维码布局逐个框选，避免码与码相互干扰。
- 如果提示标签页已切换，回到目标标签页重新点击插件。
- 如果页面不允许截图，切换到能显示该二维码的普通网页后重试。
- 背景图、Canvas、视频画面通常没有图片右键菜单，直接使用截图框选。

第一版识别常见 QR Code。低清、残缺、动态变化和特殊艺术码不保证成功。应用专用链接仅显示和复制，不直接唤起应用。

## 权限和隐私

扩展需要图片菜单、临时当前标签页访问、脚本注入、会话存储和不可见页面权限。不可见页面只在本地处理图像，便于结果直接显示在网页内。为读取跨域原图，声明了 HTTP / HTTPS 主机访问权限，安装或详情页可能显示可访问网站数据。

本地识别不上传图像或内容。读取原图会向图片原服务器请求图像；点击跳转后访问目标网页。没有云端识别、遥测或扫码历史功能。

## 更新与移除

- 更新：先关闭旧版独立扫码窗口。替换源目录文件后，在扩展管理页点击「重新加载」，并刷新二维码网页，使页内脚本重新生效。
- 如果加载的是 `D:\DSH_WorkFolder\QRCS\extension`，源码更新已写入该目录，直接在 `edge://extensions/` 中对 QRCS 点击「重新加载」，检查版本为 **1.0.2**。
- 如果加载的是自行解压 ZIP 的目录，请使用 `QRCS-1.0.2.zip` 覆盖该目录，再点击「重新加载」。
- 移除：在扩展管理页找到 QRCS，使用「删除」。

当前版本：1.0.2，识别结果改为页内小浮层，保留美化码识别修复。要求 Chromium 127 及更新内核。完整测试状态以项目 `docs/TESTING.md` 为准；用户当前两个 Edge 标签页的完整验收仍待完成。
