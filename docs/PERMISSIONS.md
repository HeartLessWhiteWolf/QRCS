# 权限与数据处理

QRCS 仅在用户主动使用识别功能时处理相关任务。解码在本机完成，运行代码与 WASM 资源均随扩展打包，不调用在线识别服务。

| 权限 | 用途 |
| --- | --- |
| `contextMenus` | 在图片右键菜单中添加「QR码识别」 |
| `activeTab` | 用户点击图标或图片菜单后，截取当前标签页网页可见区域 |
| `scripting` | 按需注入框选界面和结果浮层 |
| `storage` | 使用 `storage.session` 在扩展组件间临时传递任务 |
| `offscreen` | 在不可见扩展页面中运行本地图像处理与解码 Worker |
| HTTP / HTTPS 主机权限 | 读取用户选择的跨域原图，并按需显示当前页面界面 |

本扩展没有常驻的全站内容脚本、浏览历史读取、键盘记录、用户画像、扫码历史或跨设备同步功能。

## 网络与剪贴板

- 读取网络原图会向其原站发起请求。浏览器可能按自身 Cookie 和 SameSite 规则携带对应域的会话凭据；扩展不读取或导出 Cookie。
- 只有点击「跳转」才会访问二维码目标网站。跳转仅允许有效且不含账户密码的 HTTP / HTTPS 地址。
- 只有点击「复制」才会写入系统剪贴板。扩展不读取剪贴板。

## 临时数据

选中的图片地址、截图、选区及解码结果用于本次识别，在 `storage.session` 和处理时的内存中临时保存。正常关闭浮层或取消任务时删除对应记录；源标签页关闭时也会清理其任务。

异常遗留记录会在创建满 30 分钟后的下一次新任务时清理，并非后台定时删除。浏览器会话结束或扩展禁用、重新加载、更新、移除时，会话存储按浏览器机制清空。关闭浏览器窗口但保留后台进程，不一定结束整个浏览器会话。
