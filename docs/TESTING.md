## 浏览器集成测试

`npm run test:browser`：简体中文与英文各 **24/24**，通过。Chromium 145.0.7632.6，使用独立临时浏览器配置文件；通过 `QRCS_TEST_LANGUAGE=zh-CN` 或 `en-US` 选择测试语言。

覆盖内容如下（部分条目包含多个独立用例）：

1. 右键生产处理函数 → 本地不可见页面解码 → 页内小浮层；复制及实际新标签页跳转成功。
2. 中文换行保留，非网址禁用跳转，取消移除浮层。
3. HTML 载荷按纯文本显示，没有插入可执行元素。
4. data 图片作为原图可解码，Esc 移除页内结果。
5. 注入网页框选界面，实际拖动选区后在同一网页显示结果；没有新建系统窗口。
6. 工具栏紧凑界面的过小选区提示、反向框选与缩放坐标换算。
7. 空白选区失败后显示重新框选入口。
8. 整页四个不同二维码均可识别、切换，标明网页截图来源。
9. Esc 撤销框选并清除临时任务。
10. 与真实反馈同类的自建美化码经不可见扩展页面和本地 WASM 成功解码，结果显示在页内。
11. 完全断网时，美化码截图裁剪仍能解码，不依赖 CDN 或云服务。
12. 原图读取失败后，从整页截图中找到并解码美化码。
13. 360px 宽视口下浮层不超出页面，关闭按钮可用。
14. 所有结果显示流程结束后，浏览器系统窗口与结果标签页数量没有增加；只有用户主动点跳转时创建目标标签页。
15. 不可注入的 data 图片页配置工具栏紧凑弹层，不新增系统窗口；该紧凑界面可成功解码、取消并清除图标弹层配置。
16. 网页框选开始前和拖动途中均可右键取消，临时任务被清除，不触发识别。
17. 工具栏备用框选开始前和拖动途中均可右键取消，界面关闭并清除任务。
18. 工具栏结果区右键不会误触发取消，原有操作仍可用。
19. 网页非图片区域的菜单经生产入口进入框选，可右键取消。此项用测试截图替代 captureVisibleTab，原生 activeTab 授权不在自动测试范围内。
20. 以上三组右键行为共新增 6 项检查，完整集成测试为 22 项。
21. 没有未捕获的页面运行错误。
22. 中英文实际浏览器语言、manifest 名称与描述、工具栏标题、按钮、错误提示及无障碍标签一致。

## 修复记录

- 多码定位点互相干扰：加入重叠分区，每遮去一个已识别码后重新从整图扫描。
- 渐变圆点头像码：原真实图片上 jsQR 和普通阈值/膨胀处理失败，接入本地 ZXing-C++ / zxing-wasm 3.1.6 后修复。原样本仅在本机保存；公开仓库改用自建圆点、渐变、圆角定位框和中央图标样本进行回归。
- 独立窗口过大并出现任务栏图标：移除创建窗口的路径，普通网页改为约 420px 页内浮层，受限页面使用工具栏紧凑弹层。新增不可见扩展页面，仅用于本地图像处理。
