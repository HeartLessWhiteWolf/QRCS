# 隐私页字段与权限理由

适用版本：QRCS 1.0.3。以下内容可按 Partner Center 实际字段逐项粘贴。

## Single Purpose / 单一用途

在用户主动操作时，读取网页图片或当前网页可见区域截图中的二维码，展示解码内容，并提供复制及用户确认后的网页跳转。

## contextMenus

在图片的右键菜单中添加“QR码识别”入口。用户执行该菜单项后，扩展才处理选中的图像；不修改浏览器搜索、主页或新标签页设置。

## activeTab

用户点击扩展图标或执行图片菜单后，临时取得当前标签页访问能力，并调用 captureVisibleTab 截取该标签页的网页可见区域，用于框选识别或原图读取失败时的截图备用识别。不截取桌面、其他应用或后台标签页。

## scripting

在用户使用识别功能时，按需向当前网页注入框选界面和紧凑结果浮层。浮层读取识别结果并发送用户操作，不作为常驻内容脚本注入所有页面。受限页面无法注入时改用工具栏弹层。

## storage

仅使用 storage.session 在后台调度、不可见解码页面和结果界面之间保存本次任务，包括源标签页标识、图片地址、截图、选区与解码内容。关闭或取消任务时删除对应记录；异常遗留任务在创建满 30 分钟后的下一次新任务时清理。没有 storage.local 或 storage.sync 的扫码历史或跨设备同步功能。

## offscreen

创建不可见的扩展页面，在本机读取图像、运行 Canvas 和解码 Web Worker，使结果能够直接在网页中显示。该页面不显示为独立系统窗口，不播放媒体、不采集音视频，也不用于收集额外数据。

## http://*/* 与 https://*/*（主机权限）

用户选择的二维码图片可能位于任意网站或不同域名的图片 CDN。扩展需从扩展自身上下文读取该图片，绕开普通网页的跨域图像像素限制，并按需向当前普通网页注入框选和结果浮层。权限覆盖 HTTP 和 HTTPS 网站是为了支持任意站点上的这两项用户可见功能；不用于后台抓取、持续监视、读取浏览历史或广告追踪。原图读取失败时可以使用用户当前页面截图识别。

图片请求使用浏览器的网络机制；浏览器可能按 Cookie 与 SameSite 等规则附带目标图片域已有的会话凭据。扩展没有 cookies 权限，不读取、导出或保存 Cookie 内容。源站会像正常资源请求一样看到请求地址及网络元数据。

## Are you using remote code?

No, I am not using remote code.

全部执行代码及 WASM 解码二进制均包含在扩展 ZIP 内。二维码图像是输入数据，不作为脚本执行。`wasm-unsafe-eval` 仅允许实例化包内的 ZXing-C++ WASM，不允许远程脚本。内置第三方库可能保留上游默认 CDN 地址字符串，但 `decode-worker.js` 在调用前以本地读取的 wasmBinary 覆盖模块配置；不从 CDN 获取或执行资源。该路径已通过完全离线回归测试。

## Data usage / 数据使用说明

可填写的说明：

QRCS 会在用户主动识别时，在设备本机访问和处理选中的图片、当前网页可见区域截图、二维码内容与本次任务的标签页标识。截图可能包含网页上可见的个人信息。上述内容不上传至开发者、在线识别服务、分析服务或广告服务；不出售、不用于广告、不建立用户画像。原图获取、用户主动打开目标链接以及复制到系统剪贴板是明确披露的用户功能。

表单核对原则：

- 不要把“没有远程收集”写成“从不访问或处理任何用户数据”。本地截图和二维码内容确实会被处理。
- 如果当前表单的分类包含访问/使用的“网站内容”，应据此如实披露本地处理；如字段仅询问开发者远程收集，则说明不存在此类上传。以提交时的字段原文和微软定义为准。
- 扩展不以识别用户身份为目的收集姓名、邮箱、账户、密码、支付信息、定位信息、浏览历史、通讯记录、健康信息或键盘输入；如果这些信息出现在用户主动选择的二维码/截图中，仅作为该次识别输入在本机处理。
- 原站图片请求和用户点击跳转涉及第三方网站的正常网络访问，不能宣称“完全没有网络请求”。
- 隐私政策网址必须是公开可访问的真实 HTTPS 地址，并与上述行为保持一致。见 `privacy-policy.zh-CN.md` 和 `privacy-site/`。

## 代码核对位置

- 触发、截图和临时任务：`extension/background.js`。
- 按需注入的框选与结果：`extension/selection.js`、`extension/result-panel.js`。
- 图像请求、Canvas 与 Worker：`extension/image-pipeline.js`。
- 不可见页面：`extension/offscreen.js`。
- 包内 WASM：`extension/decode-worker.js`、`extension/vendor/`。
