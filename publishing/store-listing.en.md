## Name

```
QRCS QR Code Reader
```

## Short description (manifest)

```
Read QR codes from images with a right-click, or select an area of a page. Decode locally and preview before opening links.
```

## Long description

```
QRCS QR Code Reader is a QR Code reader for Microsoft Edge. When a QR Code appears in a web image, right-click it to read the code. For codes drawn in a background image, on a Canvas, or inside video, click the toolbar icon and drag a selection over the visible page instead.

[TWO WAYS TO READ]
Right-click any image and choose "QR码识别" (Read QR Code) to decode the code in that image. Alternatively, click the QRCS toolbar icon to select an area of the page: decoding starts when you release the mouse, and pressing Esc or right-clicking cancels the selection.

When an image sits under a page overlay, or the code is painted on a Canvas or background image, the right-click entry switches to selection mode instead. The toolbar icon does the same thing without needing the menu.

[SEE THE CONTENT BEFORE YOU OPEN IT]
Results appear in a small panel inside the page, so no separate OS window is opened. When the result is a valid HTTP or HTTPS link, you can open it in a new tab, copy it, or dismiss it. Plain text, Wi-Fi credentials and contact cards are shown verbatim. App-specific links can be copied but never launched automatically.

[LOCAL DECODING]
Images and screenshots are decoded on your device by the decoder bundled with the extension. Nothing is uploaded to the developer or to any online recognition service. The extension has no sign-in, no ads, no analytics and no scan history. Reading an original image may issue a request to the site that hosts that image; the destination site is visited only when you click the navigation button, and the system clipboard is written only when you click copy.

[COMMON STYLES AND MULTIPLE CODES]
Common QR Codes are supported, including rotated, inverted, coloured, dot-style, and codes with a centre logo. If several distinct codes are found in one image you can switch between the results. Heavily blurred, occluded, damaged or highly stylised codes depend on the actual image: keep the four corners and the surrounding quiet zone visible, and retry by selecting a smaller area or zooming the page.

[COMPATIBILITY AND PERMISSIONS]
Requires desktop Microsoft Edge on Chromium 127 or later. Standalone images and restricted pages that cannot host the in-page panel fall back to a compact toolbar popup; if it does not open automatically, click the QR badge on the extension icon. A screenshot covers only the visible area of the current tab. Browser internal pages, the extension store, PDF viewers and local files may be restricted by the browser.

The extension processes images only while you are actively using it. The image context menu, current-tab access, on-demand script injection, session storage, offscreen document and host permissions each serve the reading features described above; they are not used to read your browsing history or to monitor pages continuously. Dismissing the result panel or cancelling a task clears the corresponding temporary record, and an abandoned task is cleared on the next use after 30 minutes.
```
